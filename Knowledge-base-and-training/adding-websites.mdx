---
title: "Adding Websites"
---

Import pages from your website, blog, or docs to train the AI Double.

## **How to add a website**

1. Open **Knowledge** and click **Website URL**
2. Choose an import mode
3. Paste your URL, sitemap, or list of URLs
4. Review the discovered pages and select which ones to add
5. Start the import

## **Import modes**

| **Mode** | **What it does** |
| --- | --- |
| **Single URL** | Adds only the page you provide |
| **Whole Website** | Follows internal links, up to the max URL limit you set (at most 10,000). You can also add a URL pattern to filter pages |
| **Sitemap** | Reads sitemap XML, sitemap indexes, and robots.txt. You can filter by URL pattern |
| **CSV Import** | Paste URLs (one per line or comma-separated), or upload a CSV with URLs in any column. Only these exact URLs are imported |

## **What to know**

- Only the visible text on each page is imported. Images and hidden content aren't captured
- Duplicate URLs and previously crawled pages are excluded automatically
- Paid articles aren't supported
- Social media profiles aren't supported here. Use the social sources instead
- To update a website, delete the source and add the updated URL

## **Best for**

- Services and product pages
- About and team pages
- Blog posts
- Support docs
- Case studies and testimonials
