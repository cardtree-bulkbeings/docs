---
title: "What if sources have conflicting information?"
---

If your Double gives inconsistent answers, two of your sources may disagree.

## **How to fix conflicts**

- Check which sources might conflict
- Update or delete outdated sources
- Use Text or LLM Knowledge to state which information is correct
- Replace old files with newer versions

Keeping one current source for each fact is the most reliable fix.

## **How to prevent conflicts**

- Review sources regularly
- Set auto-refresh on social accounts so posts stay current
- Use **Sync Now** or automatic updates for Google Drive files
- Remove old versions when you upload new ones
