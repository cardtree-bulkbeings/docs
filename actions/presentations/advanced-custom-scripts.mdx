title: "Slide Scripts and AI Instructions"
---

Control what your Double says on each slide, and how it delivers the whole deck. Both live on the **Setup** tab.

**Slide scripts**

In the **Slides** section, click a slide to edit it:

- **Script** What your Double says and references for this slide
- **Slide AI instruction** Overrides the presentation-wide instruction while this slide is showing
  - Example: "Emphasise the pricing and allow more detail here"

**Behaviour**

- Tap a preset to add a line to the instruction: **Conversational**, **Ask questions**, **Keep it short**, or **Go into detail**. Combine as many as you like
- Edit **Custom AI instruction** freely, for tone, speaking style, and target length (up to 2,000 characters)
  - Example: "Mention their company name if they tell you"
  - Example: "Use technical terminology for engineers"

**What to know**

- Your Double drafts the trigger phrases and delivery instruction when it reads the deck. Review them before publishing
- A slide AI instruction only applies while that slide is showing
- Edits to a live presentation save as a draft. Click **Republish** to update it

## **Quick Reference**

| **Task** | **Steps** |
| --- | --- |
| **Create presentation** | Skills → Presentation → Choose Doubles → Add deck → Review Setup → Publish |
| **Embed on website** | Setup → Share and embed → Create link and embed code → Copy HTML or React code |
| **Share standalone** | Setup → Share and embed → Copy the link |
| **Edit existing** | Open it from Skills → Edit Setup → Republish |
| **Test presentation** | Test tab → Choose a Double → Try it as a visitor |
| **Replace deck** | Slides → Replace deck → Upload or choose from Knowledge |
| **Pause/delete** | ⋮ menu → Pause presentation or Delete presentation |
