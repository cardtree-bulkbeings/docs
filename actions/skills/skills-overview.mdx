---
title: "Skills Overview"
---

**Skills** give your Double abilities beyond chatting — practising a scenario, running an interview, handing over files, presenting a deck, or following your own instructions with tools.

**Where to find them:** **Library → Skills** (`/app/skills`) for all skills, or open a Double → **Configure → Skills** for that Double's skills.

## Skill types

| Type | What it does |
| --- | --- |
| **Role play** | People practise a conversation while your Double plays a role |
| **Interview** | Your Double asks set questions and collects the answers |
| **Share assets** | Hands files and links to visitors when they ask |
| **Presentation** | Presents a slide deck and answers questions about it |
| **Custom** | Your own instructions plus tool access, in Adaptive or Guided mode |

Files, links, and social content live in **Knowledge**. Gmail and Calendar live in **Tools**. Skills use them without you configuring them twice.

**Note:** Older built-in skills such as Display Image, Share PDF, Link Embed, and Embed Social Content are now handled through **Knowledge** and the **Share assets** skill. Gmail and Calendar skills are configured through **Tools**.

## How skills are organized

1. Go to **Library → Skills**.
2. Start with a purpose-built skill, a template, or **Build your own**.
3. Browse **Your skills** — the list shows **Name**, **Type**, **Assigned**, **Updated**, and **Status**.
4. Search with **Find anything**, or filter by type or Double.

Inside a Double, the same list is filtered to that Double, and new skills are assigned to it automatically.

## When a skill runs

A skill must be:

- **Active** — paused and draft skills do not run.
- **Assigned** to the Double the visitor is using.
- **Matched** by the conversation.

Double decides when a skill applies from its description, and exact **start phrases** give you a guaranteed trigger. Workflows can also start a skill as a step.

## Statuses

| Status | Meaning |
| --- | --- |
| **Active** | Available to run |
| **Paused** | Configured but will not run |
| **Draft** | Not saved yet |
| **Preview** | A custom skill waiting for the new agent runtime |

## What to know

- Each skill focuses on one job; multiple skills can run on the same Double.
- Skills are reusable — build once, then assign to any Double.
- Pausing keeps the configuration; deleting removes it everywhere.
- Skills that need a connected tool, a deck, or shareable files show as needing setup until that piece is ready.
- Custom skills save as a preview first.
