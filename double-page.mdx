**Home** (`/app/home`) is your starting point — it greets you ("Hello {name}! Find your AI Doubles below.") and shows every Double you have created as cards in a grid.

## Your Doubles grid

Each card shows the Double's **photo, name, job title, and public link**, plus **conversation count** and **last active** time. Clicking a card opens that Double's **Overview**.

From each card you can act without opening it:

| Action | What it does |
| --- | --- |
| **Preview** (eye icon) | Opens the Double's public page in a new tab, as visitors see it |
| **Edit** (pencil icon) | Opens the Double's Overview for configuration |
| **Share** (share icon) | Opens sharing options (link, embed) |
| **Channels dropdown** | Shows where this Double is live (Double Chat, Website, Card, Gmail, Google Chat Beta…) with **Manage all channels** |
| **Go to dropdown** | Jump straight to Identity, Persona, Voice, Knowledge, Skills, Channels, Inbox, Lead capture, or Analytics for this Double |
| **⋯ menu** | **Duplicate** the Double (suggests an available handle, e.g. name_copy) or **Delete** it |

## Creating a new Double

Click the dashed **Add new** tile next to the grid. It starts the creation flow (choose a handle, then onboard). If your plan's Double limit is reached, you'll be asked to upgrade first.

## Inside a Double: Overview

Clicking a card lands on **Overview** — the health dashboard for that Double:

- **Vitals** — conversations (30 days), leads, average intent, last active; issues link you to the right fix (Persona, Knowledge, or Voice)
- **Identity** — name, title, photo → Edit identity
- **Channels** — where this Double is available → Manage
- **Brain** — Persona, Voice, Knowledge, Actions shortcuts
- **Recent activity** — latest conversations → Open inbox

## Inside a Double: sidebar navigation

The left sidebar (with an **All Doubles** back link and a **Double switcher** to hop between Doubles) organises everything per Double:

| Section | Pages |
| --- | --- |
| **Overview** | Health dashboard |
| **Configure** | Identity, Persona, Knowledge, Skills, Voice |
| **Publish** | Channels, plus its live channel rows (Double Chat, Website Agent if embedded, Card if built — first 3 shown, "N more" and **View all channels** for the rest) |
| **Conversations** | Inbox (chats, including Google Chat threads), Lead capture (with leads count) |
| **Results** | Analytics, Earnings |

Tips: Gmail and Google Chat have no sidebar entries on purpose — reach them through the Channels hub. Google Chat is currently labelled **Beta**.

## App sidebar: global navigation

The main sidebar covers the whole workspace. **Global library pages are shared and reusable**; per-Double pages (same names with a specific Double selected) configure one Double:

| Section | Pages | For |
| --- | --- | --- |
| **Command** | Needs you (attention dot for pending items), Chats, Activity, Routines | Daily work across Doubles |
| **Doubles** | Home grid (this page) | All your Doubles |
| **Library** | Knowledge, Skills, Voice, Tools | Shared, reusable assets |
| **Conversations** | Inbox, Contacts | Every conversation and lead, all Doubles |
| **Results** | Analytics, Earnings | Performance and revenue, all Doubles |
| Bottom | Get started (hides once done), Settings, Help & Support | Account, help docs (`help.thedouble.ai`), `hello@thedouble.ai` |

Rule of thumb: use **Library** pages to build reusable assets once, and the **per-Double sidebar** to wire them into a specific Double.

## Empty state

New accounts show just the **Add new** tile — click it to create your first Double.

## FAQ

**How do I see my Double as visitors see it?** Card → Preview, or the `/{slug}` link on the card.

**How do I switch between Doubles?** The Double switcher at the top of the per-Double sidebar, or go back via All Doubles.

**Where do I manage all channels across Doubles?** Each card's Channels dropdown, or the Channels hub per Double.

**How do I delete a Double?** Card → ⋯ menu → Delete.

**How do I copy a Double?** Card → ⋯ menu → Duplicate, pick an available handle, and a copy is created.

**I hit a Double limit — now what?** Upgrade your plan for more Double slots, then use Add new again.
