title: "Skills: Sharing Assets & AI Skills"
---

**Skills** give your Double abilities beyond chatting — role-playing a scenario, running an interview, sharing files and links, presenting a deck, or following your custom instructions with tools. Open **Skills** in the sidebar (all skills), or a Double's sidebar → **Skills** (that Double's skills).

## Skill types

| Type | What it does |
| --- | --- |
| Role play | Practice scenarios (e.g. mock interview, sales practice) with difficulty, voice, and questions |
| Interview / Questionnaire | Structured question flows (e.g. lead intake, applications, feedback) |
| Share assets | One skill for the files and links your Double sends when asked |
| Presentation | Presents a deck to visitors (published decks work on all Doubles) |
| Custom | Your own instructions + tool access, in Adaptive or Guided mode |

Files, links, and social content live in **Knowledge**; Gmail and Calendar live in **Tools** — skills use them without configuring twice.

## Creating a skill

Start from **New skill**, a template (mock interview, lead intake, qualify leads, book meetings…), or **Build your own** ("describe anything") — some paths continue with AI help in Command. The editor asks for:

- **Name** and which **Doubles** use it (fixed to the current Double inside a Double's Skills)
- **When to use** — the situation that triggers it
- **Behaviour** — scenario/difficulty/questions (role play), question builder (interview), or instructions + mode (custom)
- **Tools** — tick what it may touch; read-access warnings shown per tool
- **Test/Results** tabs to try it before saving (for saved skills)

Validation: name, at least one Double, a trigger, and (for interviews) at least one question. Statuses: **Active / Paused / Draft / Preview**. Custom skills save as Preview first while the new runtime finishes.

## Sharing assets skill

"One skill for the files and links your Double can send when asked":

- Add from your **Knowledge picker**, **upload** a PDF/image (**under 10 MB**), or paste a **raw URL** — up to **25 assets** with unique names
- Delivery adapts automatically: PDF card, in-chat image, social embed, or link card
- Key rule: **knowledge used for answers is not automatically shareable** — only assets added here can be sent
- Only ready (fully processed) knowledge items can be picked

## Onboarding & AI-created skills

Choosing use cases at onboarding ("N skills · N behaviours") drafts starter skills automatically: coaching/practice become role plays, consultations/bookings/surveys become questionnaires, anything else custom (≤1,800 chars each). Skills needing a connected account, a deck, or shareable files stay in their normal setup flow and show **"needs setup after launch"** until done — they won't run before that.

## Assigning, pausing, removing

- **Assign to** (global Skills) puts a skill on chosen Doubles; inside a Double it applies there
- **Pause/Activate** from the row menu; paused skills stay configured but never run
- **Remove from this Double** keeps it in central Skills; **Delete** (global) removes it everywhere permanently
- **Presentations**: needs a deck first (Needs deck / Processing / Failed states); publishing puts it on all Doubles

Note: skills can't be shared externally person-to-person — only **presentations** have a public link/embed snippet.

## FAQ

**Why won't my skill run?** It's paused, unassigned from this Double, or waiting on setup (connected tool, deck, or shareable files). Check its status row.

**Answers vs shareable files — what's the difference?** Knowledge answers questions automatically; only assets added to the Share-assets skill can be _sent_ to visitors.

**Can visitors trigger my custom skill?** Yes, if it's Active and assigned to that Double with its tools connected.

**I deleted a skill from my Double — is it gone?** No — removing only unassigns it; it stays in global Skills. Global Delete is the permanent one.

**Why is my new custom skill in Preview?** Custom runtime support is still rolling out; Preview is the safe state until then.
